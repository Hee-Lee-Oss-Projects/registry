# Hee-Lee Oss registry

The public index of approved Hee-Lee Oss good-deed projects.

This is the canonical source that `hee-lee-oss browse` reads to discover projects. Each entry points
at a project repo under the [`Hee-Lee-Oss-Projects`](https://github.com/Hee-Lee-Oss-Projects) org, where the
project's own tasks live under `tasks/`.

- **File:** [`registry.json`](./registry.json)
- **Raw URL:** `https://raw.githubusercontent.com/Hee-Lee-Oss-Projects/registry/main/registry.json`

To get listed, open a PR adding your project entry (see the project schema in the platform repo).

## What Hee-Lee Oss is

Hee-Lee Oss turns spare AI capacity into open-source good deeds. A contributor pulls a
community-approved task, has their own coding agent do the work, and opens a PR.
